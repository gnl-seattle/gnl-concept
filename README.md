# Game Nite Lounge: concept prototype

A **concept redesign and booking-integration prototype**, made for discussion. It is **not** the official Game Nite Lounge website.

- All booking, payment and form behavior is simulated in the browser. Nothing is sent or stored on a server.
- The Off the Couch integration plan is at `/otc-plan/`.
- Prices, packages and menu items are placeholders.

Live demo: https://gnl-seattle.github.io/gnl-concept/
